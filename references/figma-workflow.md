# Figma 写入流程

1. 解析 URL 的 `fileKey` 与 `nodeId`，切换到目标页面。
2. 读取 `figma-use`；完整页面同时读取 `figma-generate-design`。
3. 先检查现有画板、字体、组件、变量和命名；优先复用同系统页面。
4. 新建独立画板或状态，不覆盖无关原稿；新画板放在现有内容右侧并留 200px 间距。
5. 先建外层画板，再逐区构建页头、查询、列表/表单、弹窗与状态。
6. 画板命名：`序号｜页面名称｜状态/版本`；页面命名：`业务模块｜版本`。
7. 核心入口添加原型：新增、查看、修改、返回、保存、展开/收起、删除和复核。
8. 覆盖层在自动布局中使用绝对定位，防止被排到画板下方。
9. 每次写入返回创建、修改、删除节点 ID。
10. 对整页和关键区域截图；检查重叠、截断、空白、字体、颜色、列宽和原型连线。

Figma 不支持 CSS 字体栈或按查看者系统自动切换字体。写入前必须查询目标文件可用字体：macOS 设计环境优先 `PingFang SC`，Windows 设计环境优先 `Microsoft YaHei`。若目标字体不可用，优先复用目标文件既有中文字体，并在交付中明确记录；不得静默替换为 Inter。HTML 交付仍使用视觉规范中的完整系统字体栈。
