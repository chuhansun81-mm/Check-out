# 页面地图与业务流程

## 一级导航

- 工作台：数据概览。
- 航司 AT 系统：收银台模板配置、交易服务配置、商户支付产品配置、复核管理。
- 系统管理：操作日志、权限管理。

## 页面集合

1. 通用模板列表：查询、新增、查看、修改、商户配置。
2. 新增/编辑通用模板：基础信息、支付方式、页面元素、实时预览、保存草稿、保存并启用。
3. 通用模板详情：基础信息、支付方式只读表、页面元素只读信息、修改入口。
4. 商户支付产品配置列表：宽表格、固定操作列、新增、修改、删除、复核。
5. 新增/编辑商户配置：优先弹窗；字段很多时使用独立页面。
6. 商户收银台配置：模板继承与商户覆盖、支付产品显示开关和拖拽排序。
7. 待复核列表：配置类型、操作类型、提交人、提交时间区间、复核入口。
8. 最近复核记录：复核结果、复核人、复核时间、意见。
9. 复核弹窗：新增/修改/删除差异、意见、驳回、通过。
10. 删除二次确认：说明复核后生效，提交删除待复核。

## 主流程

`模板列表 → 新增/编辑 → 保存草稿或提交 → 二次确认 → 待复核 → 通过/驳回 → 列表/详情`

商户覆盖流程：

`模板列表 → 商户配置 → 调整显示/顺序 → 保存配置 → 待复核 → 生效`
