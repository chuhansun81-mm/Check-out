# 页面模式

## 列表页

- 顶部：标题、说明、右侧主操作。
- 查询区：名称/ID、类型、状态、日期区间；按钮顺序“查询、重置”。
- 列表卡片左右内边距 20px；标题同时显示总数和规则说明。
- 状态用标签，操作用文字链接；危险操作使用红色。
- 分页右下对齐，显示总数。
- 宽表格设置最小列宽；操作列固定右侧，其他列横向滚动。

## 新增/编辑页

- 左上返回，标题和说明紧邻。
- 按“基础信息 → 支付方式 → 页面元素”分组。
- 右侧预览仅用于配置页；详情页默认不展示预览，除非用户明确要求。
- 底部操作栏固定，顺序“取消 → 保存草稿 → 保存并启用”。
- 短表单使用弹窗；长表单使用独立页面。

## 详情页

- 只读展示，顶部提供返回、状态和修改入口。
- 卡片内部内容撑满可用宽度，使用稳定的 3 列栅格，避免右侧大片空白。
- 基础信息避免过高卡片；字段采用标签+值。
- 支付方式表拆分“当前状态”和“展示条件”，并显示顺序。
- 页面元素使用 3 列布局；Logo 显示 40px 缩略图；主题色和辅助色均显示色块。
- 空值显示具体语义，不单独使用破折号。
- 默认不展示操作记录；如需求需要，单独设为审计模块。

## 弹窗

- 标题明确动作，正文说明影响和生效条件。
- 表单弹窗宽度需容纳字段，内容超高时弹窗体滚动，标题和按钮固定。
- 确认按钮遵循取消、次操作、主操作；危险确认使用红色。
